# Diorama City (仮称) — 仕様書 v1.0

## 1. コンセプト

制約ゼロの都市ジオラマビルダー。SimCity / Cities: Skylines のような都市開発シミュレーションから、資金・需要・インフラといった管理要素を完全に取り除き、ビル・住宅・工場・各種施設を自由に配置して都市のジオラマを作ること自体を楽しむゲーム。グラフィックはリアル志向。

参考タイトル:
- Townscaper …「置くだけで街ができる」手軽さの参考
- Cities: Skylines … 都市としての見た目の説得力の参考

## 2. プラットフォーム / 技術スタック

- 対象: PCのWebブラウザ(Chrome / Edge / Safari 最新版)
- 3D: Three.js + TypeScript
- UI: React
- 建物: プロシージャル生成(高さ・幅・色・窓パターンをパラメータ化)
- 保存: IndexedDB(自動保存)+ JSONエクスポート/インポート
- 管理: GitHub `kimi_CitySimulation`

## 3. コア体験

- 建物の完全自由配置(位置・角度ともに自由、マウスホイール等で回転)
- 重なり判定は切替式: 基本は「重なりNG(赤く警告表示)」、設定で「自由配置(重なり許容)」に切替え可能
- 道路は直線区間+交差点ベース(クリックで結節点を打ち、交差部は自動生成)
- 地形編集: ブラシによる盛り上げ/掘削。水位は全体固定で、深く掘ると自動的に川・池になる
- カメラ: 俯瞰オービット ⇔ 一人称散歩モード(WASD+マウス、目線約1.7m)をキーで切替
- 昼夜サイクル: 朝焼け〜昼〜夕景〜夜景。夜は窓の自発光・街路灯が点灯

## 4. マップ

- 実都市スケール: 約4km四方
- 海(水位方式)+ 地形編集
- パフォーマンス設計(広大マップ×リアル追求の両立のため必須):
  - LOD … 距離に応じて建物を簡易形状に自動切替
  - インスタンシング … 同形状メッシュの一括描画
  - チャンク分割 … マップを小区画に分けて描画・カリング制御

## 5. 建物プリセット(自動バリエーション付き)

- 住宅: 戸建て / 低層マンション / 高層マンション
- 商業: 小型店舗 / 商業ビル
- オフィス: 中層ビル / 高層ビル / 超高層タワー
- 工場・倉庫
- 公園・樹木
- ランドマーク施設(Phase 2以降で拡充)

各プリセットは高さ・幅・色・窓パターン・屋根形状が自動で変化し、並べるだけで単調にならない。

## 6. グラフィック

- PBRマテリアル(コンクリート・ガラス・金属の質感)
- 太陽連動の動的影
- 水面の反射と波、空・雲・遠景フォグ
- ポストプロセス: Bloom / AO(環境光遮蔽)/ トーンマッピング
- 品質プリセット: 高品質 / 標準 / 軽量(解像度スケール・影・AO等を切替)

## 7. 操作

- マウス: クリックで配置 / 右クリックで削除 / ドラッグで連続配置 / ホイールで回転
- キーボード: 一人称モードWASD、カメラ切替、Undo / Redo
- UI: 建物パレット、地形ブラシ、設定(品質・重なりモード・昼夜速度など)

## 8. 保存

- IndexedDBへの自動保存 + 複数都市スロット
- JSONでのエクスポート/インポート(都市データのファイル共有が可能)

## 9. スコープ外(初期)

- 経済・需要・インフラ等のシミュレーション要素(コンセプト上、排除)
- 災害・破壊表現
- マルチプレイ
- 車・歩行者などの生活感演出(Phase 2候補)

## 10. 開発フェーズ

- Phase 1 (MVP): 地形編集+海、建物の自由配置(重なり切替)、基本プリセット群、直線道路+交差点、昼夜サイクル、俯瞰カメラ、一人称散歩(基本版)、品質プリセット、保存/読み込み
- Phase 2: ランドマーク拡充、車・歩行者、環境音/BGM、橋、一人称モードの作り込み
- Phase 3: 公開・共有機能など
